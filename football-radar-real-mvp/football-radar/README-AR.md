# Football Radar — مشروع أولي قابل للنشر

يحتوي المشروع على واجهة عربية متجاوبة، وواجهة API، وجامع RSS مجدول، ومخطط قاعدة بيانات Cloudflare D1.

## ما تحتاجه
- حساب GitHub وحساب Cloudflare مجاني.
- لإعداد قاعدة البيانات ونشر جامع الأخبار من الطرفية: Node.js LTS وWrangler. يمكنني إرشادك خطوة بخطوة.

## 1) رفع المشروع إلى GitHub
أنشئ مستودعًا جديدًا باسم `football-radar`، ثم ارفع جميع محتويات هذا المجلد إلى جذر المستودع.

## 2) نشر الواجهة
في Cloudflare Dashboard اختر Workers & Pages → Create → Pages → Connect to Git، ثم اختر المستودع. اجعل Build command فارغًا وBuild output directory `/`، ثم انشر.

## 3) إنشاء قاعدة D1
من جهازك داخل مجلد المشروع نفّذ:

```bash
npx wrangler login
npx wrangler d1 create football-radar
```

انسخ `database_id` الناتج وضعه بدل `REPLACE_WITH_YOUR_D1_DATABASE_ID` في `wrangler.toml`.

ثم نفّذ:

```bash
npx wrangler d1 execute football-radar --remote --file=schema.sql
npx wrangler deploy
```

## 4) توصيل /api بالـ Worker
يجب توجيه مسار `/api/*` من موقع Pages إلى Worker المنشور. إعداد الربط يختلف حسب طريقة نشر الحساب. بعد إتمام الخطوات، أرسل لقطة شاشة من لوحة Cloudflare وسأرشدك لإعداد المسار الصحيح.

## ملاحظات
- مصادر RSS الحالية: BBC Sport وThe Guardian وESPN. قد تتغير الخلاصات أو قيود الوصول؛ افحصها دوريًا.
- التحديث المجدول كل 30 دقيقة بعد تفعيل Cron Trigger.
- التصنيف الحالي بالكلمات المفتاحية وليس تحققًا صحفيًا. راجع الأخبار قبل إعادة نشرها.
- النصوص تبقى بلغة المصدر حاليًا. الترجمة العربية بالذكاء الاصطناعي تتطلب مزودًا ومفتاح API محفوظًا كـ Secret على الخادم، وليس داخل HTML.
- لا تُنسخ المقالات كاملة ولا تستخدم صور الناشرين دون إذن؛ واجهة المشروع تحتفظ برابط المصدر.
- هذه نسخة MVP قابلة للتطوير وليست ضمانًا بأن كل مصدر RSS سيظل متاحًا أو أن كل الاستخدام سيبقى ضمن الحدود المجانية.
