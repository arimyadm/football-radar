# Football Radar — MVP starter

واجهة أولية عربية RTL بتصميم داكن، مبنية باستخدام Next.js وTypeScript. الأخبار الظاهرة حاليًا **بيانات تجريبية وليست أخبارًا حقيقية أو بثًا مباشرًا**.

## التشغيل محليًا

1. ثبّت Node.js 20 أو أحدث.
2. فك ضغط المشروع ثم نفّذ:

```bash
npm install
npm run dev
```

3. افتح http://localhost:3000

## ما الموجود في النسخة الأولى؟
- لوحة تحكم داكنة ومتجاوبة للهاتف والكمبيوتر.
- موجز أخبار مع بحث وتصنيف حسب الدوري ونوع الخبر.
- حفظ الأخبار محليًا أثناء الجلسة.
- واجهة أولية لقسم Content Radar.
- مخطط قاعدة بيانات أولي للمصادر والأخبار والأفكار.

## المعمارية المقترحة للنسخة التشغيلية

1. **Collectors:** مهام خلفية تقرأ RSS وواجهات APIs المسموح بها. لا تعتمد على كشط المواقع المحمية أو تجاوز الاشتراكات.
2. **Normalizer:** توحيد العناوين والتواريخ واللغات وروابط canonical.
3. **Deduplication:** بصمة URL ثم تشابه العنوان/النص لتجميع التغطيات المتعددة للقصة نفسها.
4. **Verification:** حالات واضحة: رسمي، مؤكد من مصدر موثوق، متابعة، شائعة، غير متحقق. لا يحوّل الذكاء الاصطناعي الإشاعة إلى حقيقة.
5. **AI pipeline:** ترجمة عربية، ملخص، استخراج أسماء الأندية واللاعبين، تصنيف الدوري ونوع الخبر، واقتراح زوايا محتوى مع إظهار أنها اقتراحات.
6. **Storage & delivery:** PostgreSQL، طابور مهام، تحديث الواجهة عبر SSE أو WebSocket، وتنبيهات Telegram اختيارية.

## متطلبات قبل تشغيل الأخبار الحقيقية
- اختيار مزودي RSS/API ومراجعة شروط الاستخدام وحقوق إعادة النشر لكل مصدر.
- توفير مفاتيح API الخاصة بالترجمة/التلخيص إن تقرر استخدام مزود مدفوع.
- إعداد PostgreSQL وRedis أو طابور مهام بديل.
- إعداد عامل جمع خلفي ومراقبة أخطاء ومعدلات التحديث.

## ملاحظات أمنية
- لا تضع مفاتيح API في كود الواجهة أو المستودع.
- استخدم متغيرات بيئة على الخادم فقط.
- خزّن مقتطفات وروابط وبيانات وصفية وفق ترخيص المصدر، ولا تنسخ المقالات المدفوعة كاملة.
- أضف تسجيل دخول وحماية CSRF/Rate limiting قبل نشر الموقع على الإنترنت.
